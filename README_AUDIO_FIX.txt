תיקון הקול למילון — GitHub Pages

מה יש בחבילה:
1. index.html — הגרסה המעודכנת. המילים המובנות במילון מחפשות קודם קובץ MP3 מקומי.
2. .github/workflows/generate-bulgarian-audio.yml — פעולה אוטומטית של GitHub שמייצרת את קבצי ה-MP3 פעם אחת בקול הבולגרי הנשי KalinaNeural ושומרת אותם בתיקיית audio.

אחרי שה-Action מסיים:
- נוצרת תיקיית audio ב-repository.
- GitHub Pages מפרסם אותה יחד עם האתר.
- המילים המובנות במילון מנוגנות מהקבצים המקומיים, בלי צורך לפנות ל-Google בזמן הלחיצה.

מילים שהמשתמש מוסיף בעצמו נשארות דינמיות ולכן אינן יכולות לקבל MP3 קבוע מראש; עבורן נשאר מנגנון הגיבוי של קול המכשיר/שירות חיצוני.
